## Enterprise ERP System in One Clone

This repository is a production-grade demonstration of the Flisk **Project-Stack-Resource (PSR)** model engineered specifically for **Enterprise Resource Planning (ERP)** with **100 microservices** across 7 business domains: Finance, HR, Inventory, Sales, Manufacturing, Supply Chain, and Analytics.

You declare your enterprise services in simple `service.json` manifests. Flisk automatically discovers the landscape, resolves cross-stack dependencies, allocates dynamic port bindings, and generates local Docker, Vite, environment variables, and TypeScript plumbing inside `.autogenerated/`.

## Run It


> **Repository-pinned CLI (optional):** Run `bun install` from the repository root to install the version pinned in `package.json`. Use `bun run flisk:project` to initialize project config, `bun run flisk:dry-run` to preview startup, or `bun run flisk:up -- <stack>` to start a stack. The global npm and standalone binary installation paths remain available.

### Prerequisites

- [Docker](https://docs.docker.com/get-docker/) is running.
- [Tilt](https://docs.tilt.dev/install.html) is installed.
- [Bun 1.2+](https://bun.sh/docs/installation) is installed.
- [Flisk CLI](https://github.com/flisk-sh/flisk#installation) is available as `flisk`.

```bash
git clone https://github.com/flisk-sh/flisk-erp-system.git
cd flisk-erp-system

# Spin up the entire Enterprise ERP landscape
flisk up
```

Flisk discovers all 7 stacks and their 100 underlying resources, allocates non-conflicting ports, and starts the containerized execution graph.

```bash
# Start a specific domain stack (e.g. Finance, HR, Sales, etc.)
flisk up finance
flisk up hr
flisk up inventory
flisk up sales
flisk up manufacturing
flisk up supply_chain
flisk up analytics

# Inspect all running enterprise services
flisk status

# Stop the entire landscape cleanly
flisk down
```
